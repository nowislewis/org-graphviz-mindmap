* Overview

Generate clean, hierarchical mind maps from Org mode files using Graphviz.

[[./example-20251121-175128.svg]]
* Features

- 📊 *Clean Hierarchy*: Top-to-bottom layout with clear parent-child relationships
- 🎨 *Level-based Coloring*: Same-level headings share the same color and height
- 🔗 *Org-ID Links*: Dashed blue arrows show cross-references between nodes
- ✅ *TODO Keywords*: Color-coded keywords (TODO in red, DONE in green, etc.)
- 📊 *Progress Indicators*: Highlighted progress markers like [1/3] or [33%]
- 📤 *Multiple Formats*: Export to PNG, SVG, or PDF
- ⚡ *Simple & Efficient*: Clean, optimized codebase

* Installation

#+begin_src elisp

* Usage

Open an Org file and run ~M-x org-graphviz-mindmap-create~. The mind map is automatically generated, saved to =/tmp/= with a timestamp, and opened - no prompts needed.

To view the DOT source code: ~M-x org-graphviz-mindmap-show-dot~

* Example

Given this Org file:

#+begin_src org
,* Project [1/3]
:PROPERTIES:
:ID: project-id
:END:

,** TODO Design
,*** Wireframes
,*** Mockups

,** DONE Development [100%]
:PROPERTIES:
:ID: dev-id
:END:

,*** Backend
,*** Frontend

,** Testing
See [[id:dev-id][Development]] for context
#+end_src

The mind map will show:

- *Level 1* (Project): Light blue node with ~[1/3]~ in blue
- *Level 2*:
  - ~TODO Design~: "TODO" in red, medium blue node
  - ~DONE Development [100%]~: "DONE" in green, "[100%]" in blue
  - ~Testing~: medium blue node
- *Level 3* (Wireframes, Mockups, Backend, Frontend): Darker blue nodes
- *Solid arrows*: Parent → child relationships
- *Dashed blue arrow*: Testing → Development (org-id link)

* Configuration

** Output Format

#+begin_src elisp
(setq org-graphviz-mindmap-output-format "svg")  ;; "png", "svg", or "pdf"
#+end_src

** Level Colors

Customize colors for each level (same level = same color):

#+begin_src elisp
(setq org-graphviz-mindmap-level-colors
      '("#FFF3E0" "#FFE0B2" "#FFCC80" "#FFB74D" "#FFA726" "#FF9800"))
#+end_src

Default is a blue gradient:
- Level 1: ~#E3F2FD~ (very light blue)
- Level 2: ~#BBDEFB~ (light blue)
- Level 3: ~#90CAF9~ (medium blue)
- Level 4: ~#64B5F6~ (blue)
- Level 5+: ~#42A5F5~ (deeper blue)

** TODO Keywords

By default, TODO keywords are colored within node labels (only the keyword itself, not the entire node):

- *TODO*: Red (~#D32F2F~)
- *DOING*: Orange (~#F57C00~)
- *DONE*: Green (~#388E3C~)
- *CANCELLED*: Gray (~#757575~)
- *WAITING*: Yellow (~#F9A825~)

Customize TODO keyword colors:

#+begin_src elisp
(setq org-graphviz-mindmap-todo-colors
      '(("TODO" . "#FF0000")
        ("DONE" . "#00FF00")))
#+end_src

Disable TODO keyword coloring or make them non-bold:

#+begin_src elisp
(setq org-graphviz-mindmap-include-todo-keywords nil)  ; Hide TODO keywords entirely
(setq org-graphviz-mindmap-todo-bold nil)              ; Make TODO keywords non-bold
#+end_src

** Progress Indicators

Progress indicators like ~[1/3]~ or ~[33%]~ are automatically highlighted in blue (~#1976D2~).

Customize progress indicator appearance:

#+begin_src elisp
(setq org-graphviz-mindmap-progress-color "#FF5722")  ; Change color
(setq org-graphviz-mindmap-progress-bold nil)         ; Make non-bold
#+end_src

* Visual Features in Detail

** Color System

The package uses a dual-color system:

1. *Node Background Colors*: Based on heading level (Level 1 = light, Level 2 = medium, etc.)
2. *Text Colors*: Independent coloring for:
   - TODO keywords (only the keyword itself, e.g., "TODO" in red)
   - Progress indicators (e.g., "[1/3]" in blue)
   - Regular text (black)

This means a node like ~TODO Design [2/5]~ will have:
- Node background: Based on its level
- "TODO": Red text
- "Design": Black text
- "[2/5]": Blue text

** Link Types

- *Solid black arrows*: Hierarchical parent → child relationships
- *Dashed blue arrows*: Cross-references via org-id links (don't affect layout)

* How It Works

1. *Parse*: Uses ~org-element-parse-buffer~ to extract all headings
2. *Group*: Groups headings by level for rank alignment
3. *Generate DOT*: Creates Graphviz DOT code with:
   - ~rank=same~ for same-level nodes (ensures equal height)
   - HTML labels for colored text within nodes
   - Level-based node background colors
   - Hierarchical edges (parent → child)
   - Org-id link edges (dashed, constraint=false)
4. *Render*: Calls ~dot~ to generate the image

* Technical Details

- *Layout*: Top-to-bottom (~rankdir=TB~) with ~rank=same~ grouping for equal-height same-level nodes
- *Nodes*: Rounded box shape with level-based background colors and HTML labels for text coloring
- *Edges*: Solid for hierarchy (2px), dashed for org-id links (~constraint=false~ to avoid layout interference)
- *Text Styling*: Graphviz HTML labels (~<FONT COLOR="">~, ~<B>~) for independent TODO/progress coloring

* Troubleshooting

** "dot: command not found"

Install Graphviz (see [[*Prerequisites][Prerequisites]] above).

** "Not in Org mode"

Ensure your current buffer is an Org file (=.org= extension).

** Large files are slow

For files with 100+ headings, generation may take a few seconds. Consider:
- Using SVG format (smaller file size)
- Breaking into smaller Org files

* API

** Functions

- ~org-graphviz-mindmap-create~: Main command - generates mind map, saves to =/tmp/=, and opens it automatically
- ~org-graphviz-mindmap-show-dot~: Display generated DOT source code in a buffer

** Customization Variables

- ~org-graphviz-mindmap-output-format~: Output format (default: "png")
- ~org-graphviz-mindmap-include-todo-keywords~: Include TODO states (default: t)
- ~org-graphviz-mindmap-level-colors~: Color list for levels (default: blue gradient)
- ~org-graphviz-mindmap-todo-colors~: Color map for TODO keywords (default: TODO=red, DONE=green, etc.)
- ~org-graphviz-mindmap-todo-bold~: Make TODO keywords bold (default: t)
- ~org-graphviz-mindmap-progress-color~: Color for progress indicators (default: "#1976D2")
- ~org-graphviz-mindmap-progress-bold~: Make progress indicators bold (default: t)

** File Locations

Generated files are saved to the system temporary directory:
- Linux/macOS: =/tmp/=
- Windows: =%TEMP%=

File naming pattern: ~<org-file-name>-<timestamp>.<format>~

Example: If you run ~org-graphviz-mindmap-create~ on ~project.org~ at 2:41 PM:
- Image: =/tmp/project-20251121-144143.png=
- DOT source: =/tmp/project-20251121-144143.dot=
